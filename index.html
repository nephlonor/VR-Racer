Before you start (iPhone 15 Pro)

Mobile Safari does not ship WebXR, so you'll open this page through a free bridge app that exposes ARKit + LiDAR to web pages.

  1. Install Variant Launch from the App Store.
  2. Open Variant Launch and paste this page's URL.
  3. Tap Start AR below.

LiDAR is used implicitly by ARKit to detect walls and the floor — accuracy is best on iPhone Pro models.
